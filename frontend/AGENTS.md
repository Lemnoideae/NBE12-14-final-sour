# 프로젝트 작업 지침

Last updated: 2026-11-08 19:17 +0900

## 기획서 참조와 문서 작성

- 기능을 설계·구현·검토하거나 작업 문서를 작성·수정하기 전에 `docs/4차-프로젝트-기획서(261107).html`의 관련 항목을 읽고 기준으로 삼는다. 범위는 4장(MVP·시나리오), 데이터 모델·기능 흐름은 6장(ERD·시퀀스 다이어그램 이미지 포함), 어뷰징·성능은 10·11장을 확인한다.
- 기준 기획서는 사용자 지시(2026-11-08)에 따라 261106판에서 261107판으로 바뀌었고 261106판은 삭제했다. 이전 작업 문서의 `docs/4차프로젝트기획서(261106).html:행` 인용은 당시 판 기준이며 git 이력에서 확인한다.
- **필수와 선택:** 기획서 4-1의 필수 기능과 4-2의 선택 기능을 구분한다. **4-2 “MVP 기능 구현 후 추가 기능”(261106판의 “의도적으로 제외한 기능(Out of Scope)”)은 기본 MVP에서 필수가 아닌 선택 사항이라는 의미이며, 삭제 대상이나 구현 금지가 아니다.** 사용자 지시에 따라 추가·유지·확장·보류 및 우선순위가 달라질 수 있다. 목록에 있다는 이유만으로 기존 기능을 제거하거나 요청된 작업에서 빼지 않는다.
- 작업 문서에는 기획서의 요구, 사용자가 명시한 변경·추가 지시, 에이전트의 권고, 목업 한정 단순화·임시 값을 구분해 적는다. 선택 기능을 포함할 때는 그 범위와 적용 지시를 표시하며, 지시가 없으면 필수 기능 완료의 선행 조건으로 만들지 않는다.
- 기획서와 후속 지시가 다르면 사용자 지시를 해당 범위에 적용하고 원문·변경 내용·출처를 함께 남긴다. 기존 승인 사항은 `docs/261106-1941-mockup_revision_plan.md`에서 확인한다. 에이전트의 제안이나 현재 구현만으로 기획서가 변경됐다고 간주하지 않는다. 해결되지 않은 차이는 명시하고 사용자 확인을 받는다.
- 목업의 로컬 계산·실패 시연과 실제 서비스의 서버 인증·권한·정합성·성능 검증을 구분한다. 목업 단순화를 최종 서비스 정책으로 기록하지 않는다.

## 문서 변경 완료 기준

- 필수 요구와 완료 기준을 기획서의 관련 항목에 대조하고 `파일:행` 또는 절 번호로 근거를 남긴다. 선택 기능은 현재 지시에 따른 적용 범위를 확인한다.
- 문서 링크·소스 인용·변경 diff를 확인하고, 구현·검증된 사실과 향후 작업을 분리한다. 문서의 `Last updated:`를 실제 수정 시각으로 갱신한다.

## 검토 결함의 위험도와 수정 시점

사용자 지시(2026-11-07)에 따라 검토에서 발견한 결함을 4단계 위험도로 분류하고, 위험도에 따라 수정 시점을 정한다.

| 위험도 | 기준 | 처리 |
|---|---|---|
| 고위험 | 보안·권한 우회, 데이터 손상·유실, 빌드·테스트 실패, 필수 기능(기획서 4-1) 또는 현재 단계 완료 기준 미충족 | 현재 단계에서 즉시 수정. 다음 단계 진입 차단 |
| 중위험 | 런타임 오동작 가능성(예: React 순수성 위반, 전역 상태 공유, 경쟁 조건), 테스트 격리 붕괴, 이후 단계의 설계를 제약하는 구조 결함 | 현재 단계에서 수정. 다음 단계 진입 차단 |
| 저위험 | 현재 화면·동작에 드러나지 않는 하드코딩, 목업 데이터 불일치, 일관성·가독성 문제 | 치명적이지 않으면 보류하고 이연 목록에 기록 |
| 미위험 | 산출물 형식·문구, 표기, 사소한 스타일 | 보류하고 이연 목록에 기록 |

- 저·미위험이라도 다른 결함과 결합해 고·중위험으로 이어지거나 사용자가 즉시 수정을 지시하면 현재 단계에서 수정한다.
- 이연 항목은 작업 폴더의 `deferred.md`(예: `.agent-workflow/<job-id>/deferred.md`)에 위험도, 위치(`파일:행`), 내용, 발견 시점, 해소 조건을 남긴다. 단계 완료 보고에는 이연 항목 수와 경로를 적는다.
- 위험도 판정은 검토자의 추론이므로 근거를 함께 적고, 판정이 애매하면 높은 쪽으로 분류한다.
- 이연했다고 해서 해결된 것으로 보고하지 않는다. 최종 검토 단계(P4) 전에 이연 목록을 다시 판정한다.
