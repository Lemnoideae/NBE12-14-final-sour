# [전국 랭킹] 모바일 UX 드래그 무한스크롤 구현 계획서

단일 폰 목업 내에서 최상단 TOP 3 명예의 전당 포디움부터 76위까지 끊김 없이 마우스 드래그 및 모바일 터치 스와이프로 탐색할 수 있는 일체형 무한스크롤 UX를 구축합니다.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> 사전 질의응답을 통해 확정된 핵심 설계 방향입니다.
> - **적용 대상**: 기존 분리형(Screen 1 & 2)에서 **단일 폰 목업 일체형 드래그 스크롤**로 통합 구현하여 끊김 없는 모바일 경험 제공.
> - **제스처 방식**: 모바일 터치 스와이프와 PC 마우스 클릭-드래그(Pointer 이벤트 및 관성 스크롤) 동시 지원.
> - **무한스크롤 방식**: 하단 스크롤 도달 시 레트로 픽셀 로딩 도트 애니메이션과 함께 10개교 단위로 순차 데이터 추가 로드 (최대 76개교).

- **Confirmed Decision 1**: 단일 일체형 폰 화면에서 상단 포디움과 4위 이하 리스트가 한 뷰포트 안에서 자연스럽게 스크롤됩니다.
- **Confirmed Decision 2**: 포디움이 화면 위로 스크롤 아웃되면 상단 탭 아래에 `👑 1위 KAIST` 콤팩트 요약바가 고정(Sticky)되고, 7위(내 학교: 한양대)가 뷰포트에서 벗어났을 때만 하단 고정바가 나타납니다.
- **Confirmed Decision 3**: 탭/행 클릭과 드래그 제스처가 간섭되지 않도록 최소 드래그 판정 거리(Threshold: 6px)를 적용합니다.

---

### 1. Overview & Core Concept

- **What It Does**: 사용자가 모바일 폰 목업 내부를 손가락으로 밀어 올리거나 마우스로 드래그하여, 1위부터 76위까지 전국 대학 순위를 부드러운 스크롤과 무한 로딩으로 연속 탐색할 수 있습니다.
- **Target Audience / Persona**: 캠퍼스 키우기 플레이어로서 우리 학교(한양대)의 순위 변동과 라이벌 대학(고려대, 성균관대 등)의 격차를 실시간으로 비교 확인하고자 하는 대학생 사용자.
- **Key Value**: 정적인 스크린샷 뷰를 탈피하여 실제 모바일 앱과 동일한 손맛(자연스러운 스와이프 가속/감속)과 무한 스크롤 탐색 경험을 제공합니다.

---

### 2. User Experience & Visual Design

#### Key User Flows
1. **초기 진입**:
   - 상단 헤더('대대대 전국 랭킹 대항전')와 3개 탭(학교/학과/개인) 아래 잔디 언덕 위의 **TOP 3 포디움**(1위 KAIST, 2위 부산대, 3위 전남대)이 화려하게 노출됩니다.
   - 포디움 바로 아래에 4위부터 12위까지의 대학 목록이 이어집니다.
   - 7위 한양대(내 학교)가 초기 화면에 보이므로 하단 고정바는 숨겨져 뷰포트 개방감을 극대화합니다.
2. **드래그 & 스크롤 탐색**:
   - 리스트 영역을 마우스나 터치로 위로 끌어올리면 포디움이 부드럽게 위로 밀려 올라갑니다.
   - 포디움이 뷰포트 밖으로 사라지는 순간, 탭 하단에 콤팩트한 **1위 고정바 (`👑 1 KAIST 2,903,118점`)**가 부드럽게 나타납니다.
   - 7위 한양대 행이 화면 위로 벗어나면 하단에 **황금빛 테두리의 '내 소속 실시간 순위' 고정바**가 떠올라 언제든 내 학교의 순위와 점수를 놓치지 않게 합니다.
   - 우측 하단에는 **'▲ 맨 위로' 플로팅 픽셀 버튼**이 나타나 원터치로 포디움 최상단 복귀가 가능합니다.
3. **무한스크롤 추가 로딩**:
   - 스크롤이 현재 목록의 하단에 근접하면 점선 박스 안에서 3개의 앰버색 픽셀 도트가 반짝이는 `더 불러오는 중… (N / 76)` 애니메이션이 작동합니다.
   - 350ms 후 다음 10개 대학(13~22위, 23~32위 …)이 순차적으로 추가되며 끊김 없이 계속 스크롤됩니다.

#### Visual Identity & Theme
- **컬러 팔레트**: 16-bit 코지 파밍 시뮬레이터 톤 (배경 크림 양피지 `#fdf5df`, 잔디 그린 `#38a134`, 앰버 우드 `#8b5327`, 황금 옐로우 `#facc15`, 다크 브라운 라인 `#261608`).
- **타이포그래피**: 넥슨 메이플스토리체(`font-pixel` / `font-maple`) 중심 본문 및 8-bit 프레스 스타트 2P(`font-press-start`) 숫자 폰트 조합.
- **피드백 & 인터랙션**: 드래그 중에는 `cursor-grabbing` 커서로 변경되며, 마우스를 뗄 때 자연스러운 관성 감속(Deceleration)을 적용합니다.

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: 2-Phone 정적 분리 vs 단일 폰 일체형 제스처 뷰**
  - *Chosen Approach*: 단일 폰 목업을 중앙에 배치하고 실제 모바일 터치 및 마우스 드래그가 가능한 일체형 인터랙티브 폰 화면(`RankingScreenPhone.tsx` 또는 개선된 `RankingScreenUnifiedPhone.tsx`)으로 전환.
  - *Why*: 두 개로 쪼개진 정적 화면보다 사용자가 직접 만져보며 무한스크롤을 체감하는 것이 모바일 UX의 본질에 부합합니다.
  - *Alternatives Considered*: 2개의 폰에 각각 스크롤을 달 경우 포디움과 하위 순위 간 연속성이 단절되는 어색함이 있었습니다.

- **Decision 2: Pointer Events 기반 커스텀 드래그 스크롤**
  - *Chosen Approach*: HTML5 네이티브 터치 스크롤(`overflow-y-auto` + `-webkit-overflow-scrolling: touch`)을 유지하면서, PC 데스크톱 환경에서도 모바일처럼 드래그할 수 있도록 `PointerEvent` 기반의 드래그 핸들러를 장착.
  - *Why*: 모바일 실기기에서는 100% 네이티브 부드러움을 누리고, PC 웹 브라우저 미리보기 창에서도 모바일 폰을 직접 만지듯 마우스로 스와이프할 수 있습니다.

- **Decision 3: 클릭과 드래그의 충돌 방지 (Drag Threshold)**
  - *Chosen Approach*: 포인터가 6px 이상 이동한 경우에만 스크롤로 판정하고, 6px 미만 탭 동작은 대학 상세 또는 탭 전환 클릭 이벤트로 처리.
  - *Why*: 드래그 도중 실수로 행을 클릭하거나 탭이 눌려 흐름이 끊기는 문제를 완벽히 방지합니다.

### 4. Technical Architecture & Data Strategy

```
┌─────────────────────────────────────────────────────────────┐
│                 RankingScreenPhone (Unified)                │
├─────────────────────────────────────────────────────────────┤
│  1. Top Bezel & Screen Header ('전국 랭킹 대항전' · 5s 갱신)  │
│  2. Top Tabs (학교 순위 / 학과 순위 / 개인 순위)                │
│  3. [Sticky] Compact 1st Summary (포디움 스크롤 아웃 시 등장)   │
├─────────────────────────────────────────────────────────────┤
│  4. [Drag-Scroll Viewport] (useDragScroll Hook)             │
│     ├── TOP 3 Podium Stage (카이스트, 부산대, 전남대)          │
│     ├── Ranks 4~N School Cards (한양대 7위 포함)              │
│     └── Infinite Loading Indicator (도달 시 +10개교 추가)       │
├─────────────────────────────────────────────────────────────┤
│  5. [Fixed Overlays]                                        │
│     ├── Floating '▲ 맨 위로' Pixel Button (스크롤 > 200px)     │
│     └── Smart Pinned My School Bar (7위 비노출 시 고정)       │
│  6. BottomNav ('순위' 활성화)                                │
└─────────────────────────────────────────────────────────────┘
```

#### 수정 대상 파일 및 역할
1. **`src/hooks/useDragScroll.ts` (신규 생성)**:
   - 마우스 드래그(`pointerdown`, `pointermove`, `pointerup`) 및 속도(velocity) 기반 부드러운 스크롤 관성 감속 훅.
   - 드래그 중 텍스트 선택 방지 및 클릭 간섭 방지 플래그 제공.
2. **`src/components/RankingScreenPhone.tsx` (개선/단일 폰 고도화)**:
   - 포디움과 리스트를 하나의 `useDragScroll` 스크롤 컨테이너로 통합.
   - `visibleCount` 상태를 관리하여 하단 도달 시 10개씩 증가 (`slice(3, visibleCount)`).
   - 스크롤 오프셋 감지로 `isPodiumScrolledOut` 및 `isMySchoolVisible` 상태를 실시간 연동.
3. **`src/components/TwoPhoneRankingComparison.tsx` & `src/App.tsx`**:
   - 사용자가 드래그 무한스크롤을 직접 체험할 수 있도록 네비게이션 및 모드 연동.
