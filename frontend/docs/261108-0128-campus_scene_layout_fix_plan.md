Last updated: 2026-11-08 01:50 +0900

## 1. 결론

- 가시성이 낮은 근본 원인은 **카메라가 없다는 점**이다. 장면 논리 크기(360×400)와 캠퍼스 화면 크기(내부 358×367 CSS px)가 거의 같아 에셋이 **약 1배**로 표시된다. 학생 6×12px, 고양이 5×6px, 건물 70~150px 폭이므로, 확대된 근경으로 그린 기존 성장 시트(`src/assets/images/campus_growth_5x2_final_1793921090067.jpg`)보다 모든 것이 작고 빈 잔디가 넓다.
- 좌표가 어색한 원인은 **건물에 바닥 면적(footprint) 정보가 없다는 점**이다. 길·광장 다각형과 건물이 서로 독립된 화면 좌표로 손으로 배치되어 길이 건물 밑을 관통하거나, 건물이 길·광장과 연결되지 않고 잔디 위에 떠 있다.
- 화면 위 UI(레벨 라벨 3개, 방명록 게시판, 시연 손가락)가 장면의 핵심 오브젝트를 가리며, `preserveAspectRatio="slice"` 때문에 위아래 약 15px가 잘린다. 이 영역을 배치 데이터가 알지 못한다.
- **권고(에이전트):** ① 레벨별 카메라(중심·배율) 도입, ② 아이소메트릭 타일 격자 좌표와 건물 footprint로 배치 데이터 재작성, ③ UI 안전 영역을 배치 검증에 포함, ④ 스크린샷 기반 시각 회귀 스크립트 추가. 4단계(C1~C4)로 진행한다. 카메라 배율 방식은 3절의 사용자 결정이 필요하다.

## 6. 설계 (에이전트 권고)

### 6-1. 카메라

- `CampusLayout`에 `camera: { cx, cy, zoom }` 추가. `CampusScene`은 viewBox를 `(cx - w/2, cy - h/2, w, h)`로 계산한다(`w = 360 / zoom`, `h = w × 컨테이너 높이/폭`).
- 컨테이너 비율은 `ResizeObserver`로 측정해 viewBox 높이를 맞추고 `preserveAspectRatio="xMidYMid meet"`로 바꿔 숨은 잘림(P2)을 없앤다. 측정 전 첫 렌더는 기본 비율 1:1.025를 쓴다.
- `CampusSceneLights`도 같은 viewBox를 써야 불빛이 어긋나지 않는다(`CampusScene.tsx:128-131`). viewBox 계산을 한 함수로 모은다.
- 다른 사용자 클릭 파티클은 % 좌표(`CampusView.tsx:213`)라 카메라와 무관하다(확인). 학생 귓속말 위치도 % 좌표다.

### 6-2. 격자 좌표와 footprint

- 아이소메트릭 타일(32×16, 2:1) 격자 좌표 `(i, j)` → 장면 좌표 변환 함수를 둔다. 지형(`isoDiamond`, `isoStrip`)과 오브젝트를 격자 좌표로 기술한다.
- 건물 에셋에 footprint(타일 수 `w × d`)와 정문 위치를 manifest 보조 데이터로 추가한다. 값은 에셋 이미지를 보고 사람이 정한다(목업 값).
- 길은 "정문 → 광장 → 장면 밖" 경로 목록으로 기술하고 `isoStrip`을 이어 만든다.
- 건물 바닥에 기단(footprint 다이아몬드, 어두운 잔디나 보도 텍스처)을 그려 P4를 해결한다.

### 6-3. 안전 영역

- 화면 오버레이 영역을 % 단위 상수로 정의한다: 위쪽 라벨 띠, 왼쪽 아래 방명록, 오른쪽 아래 라벨, 첫 화면 시연 손가락(52%, 46%, 40×40px + "터치!").
- `layout.features`가 가리키는 핵심 오브젝트의 경계 상자가 카메라 적용 후 안전 영역과 겹치면 검증 실패로 처리한다. 장식(나무·소품)은 겹쳐도 허용.

### 6-4. 배치 검증 확장(`validateCampusLayouts`)

추가 규칙:
1. 건물 footprint끼리 겹침 금지
2. 길·광장 다각형이 건물 footprint를 관통 금지(기단 제외)
3. 핵심 오브젝트가 카메라 영역 안에 완전히 들어오고 안전 영역과 겹치지 않음
4. 오브젝트 anchor가 카메라 영역 하단 여백 안(밑동 잘림 방지)
5. 골대처럼 짝을 이루는 소품은 지정 지형 안(선택 규칙)
