Last updated: 2026-11-10 20:48 +0900

사용자가 2026-11-10에 요청한 두 과제를 작업 단위로 나누고, 변경 위치·완료 기준·검증 방법을 정한다. 사용자 지시(2026-11-10, “기본값으로 진행해줘. (J부터)”)에 따라 §6의 Q1~Q7을 모두 기본값으로 정하고 J→V 순서로 구현했다. 진행 결과는 §9에 적었다. J는 PR #55로 병합했고, V는 이 문서와 함께 `feat/v-visit-ui` PR로 병합한다.

### 2-2. 제주 지도

좌표는 지도 설계 프레임(392×530)의 백분율이다(`schoolMapLayout.ts:37`). 지도 이미지 상자는 392×584이고 위로 27px 밀려 있다. 그래서 이미지는 프레임 y −5.1%~105.1%를 덮는다(`MapArt.tsx:33`).

| 대상 | 현재 좌표(x, y %) | 확인 결과 |
|---|---|---|
| 제주도 섬(`islands.png` 최대 연결 성분, 9,484px) | x 16.6~34.8, y 94.9~103.4, 중심 (25.7, 99.1) | Python으로 연결 성분을 계산해 프레임 %로 변환했다 |
| 제주대 `jejunu` | (26, 92)(`schoolMapLayout.ts:115`) | 섬 북쪽 끝(94.9)보다 위 → **바다** |
| 제주국제대 `jeju_intl` | (33, 93)(같은 행) | 바다 |
| 제주 권역 버블 | (28, 92)(`:100`) | 바다 |
| 제주 카메라 `regionViewport('제주')` | `{cx 29.5, cy 92.5, zoom 4}` | `npx tsx`로 실행해 확인. 학교 두 점의 중심을 카메라 중심으로 잡는다(`:193-204`) |

- 캡처(`03-map-jeju.png`)를 보면 두 학교 버튼이 화면 가운데 바다에 떠 있고, 섬은 지도 영역 아래쪽 1/3에 걸쳐 있다.
- **원인(추론):** 손으로 정한 좌표가 섬보다 2~3%p 위에 있고, 카메라가 그 학교 좌표를 중심으로 잡는다.
- **전국 지도(관련 현상, 요청 범위 밖):** 가장 좁은 지도 영역 기준으로 전국 화면은 프레임 y 약 4.9~95.1%만 보인다(`mapLayerFit`). 그래서 섬은 거의 화면 밖에 있다. 캡처 `02-map-national.png`에서는 제주 버블이 지도 아래 가장자리에 걸려 “지역을 눌러 대학을 확인하세요” 안내와 겹친다. §6 Q6에서 범위를 묻는다.

## 3. J1·J2 — 제주 학교 위치와 확대 초점

**목표 [지시]:** 제주 권역을 누르면 제주도가 지도 영역 가운데 오고, 두 학교 버튼은 섬 위에 놓인다.

### 3-1. J2 섬 경계를 데이터로 남긴다

- `scripts/map/split_layers.py`가 섬을 분리할 때 가장 큰 섬 성분(제주)의 경계 상자를 `layers.json`에 `"jeju": { "x0", "y0", "x1", "y1" }`(이미지 px)로 함께 기록한다.
  - 같은 입력이면 같은 출력이 나오므로, 기존 `npm run map:check`가 이 값도 함께 검사한다.
  - **대안:** 경계 값을 `schoolMapLayout.ts`에 상수로 직접 적는다. 스크립트를 고치지 않아도 되지만, 지도 이미지를 다시 분리하면 값이 어긋나도 알 수 없다. 그래서 스크립트 출력 방식을 권한다.
- `schoolMapLayout.ts`에 `REGION_FOCUS`(권역별 고정 카메라)를 두고, 제주만 섬 상자로 정한다.
  - 중심은 섬 상자 중심인 약 (25.7, 99.1)이다.
  - 배율은 기존 최대값 4를 유지한다.
    - 가장 좁은 지도 영역(336px)에서 배율 4로 보이는 폭은 프레임의 약 24.4%이고, 섬 폭은 18.2%다. 좌우에 약 3%p씩 바다가 남는다(계산, 추론).
    - 세로로 보이는 범위는 약 87.8~110.4%다. 105.1%보다 아래는 T7의 절차적 바다(`-inset-full`)가 채우므로 빈 곳이 생기지 않는다(T7 기록, 브라우저 재확인 필요).
- `regionViewport(region)`은 `REGION_FOCUS`에 값이 있으면 그 값을 먼저 돌려준다. 다른 권역의 계산은 바꾸지 않는다.

### 3-2. J1 학교 좌표를 섬 위로 옮긴다 [목업]

- 좌표는 실제 위경도가 아니라 **목업용 배치**다(`schoolMapLayout.ts:2-3` 주석).
- 두 학교 모두 제주시, 곧 섬 북쪽에 있다. 실제 위치는 미검증이므로 구현 시 확인한다. 이를 반영해 북쪽 해안 안쪽에 둔다.

| 학교 | 현재 | 초기값 [권고] | 근거 |
|---|---|---|---|
| 제주대 | (26, 92) | (24.5, 96.8) | 섬 중심 (25.7, 99.1), 반지름 (9.1, 4.25)인 타원 안쪽의 약 32% 위치(계산) |
| 제주국제대 | (33, 93) | (29.0, 97.4) | 같은 타원의 약 15% 위치. 제주대와 x로 4.5%p 떨어져 있어, 배율 4에서 약 70px 간격이므로 마커 폭 44px보다 넓다(계산) |

- 최종 값은 브라우저 확인으로 정한다.
  - 마커 기준점이 섬의 불투명 픽셀 위에 있어야 한다.
  - 두 마커가 겹치지 않아야 한다.
  - 한라산 그림을 크게 가리지 않아야 한다.
- 제주 권역 버블 `(28, 92)`와 리본 좌표는 전국 화면 문제(Q6)와 묶여 있으므로, Q6 답에 따라 함께 옮긴다.

1. 제주 확대 시 섬 상자 중심이 지도 영역 중심에서 가로·세로 ±8px 안에 있다. 390×844와 360×640에서 측정한다.

4. `npm test`, `npm run map:check`, `tests/e2e/map-art.mjs`, `tests/e2e/map-layout.mjs`가 모두 통과한다.

## 4. V1·V2 — 방문 화면을 메인 형식으로

**목표 [지시]:** 다른 학교를 볼 때도 메인 게임 화면의 UI 형식(헤더, 큰 캠퍼스, 캠퍼스 위 버튼, 푸터)을 그대로 쓴다. 방문이라는 사실과 관전 제약은 분명히 보이게 한다.

### 4-1. 설계 방식

| 방식 | 장점 | 단점 |

### 4-5. 완료 기준

1. 방문 화면이 메인과 같은 골격(헤더 2행, 채움 캠퍼스, 네 모서리 오버레이, 미리보기 바 + 내비)으로 보인다. 위 브라우저 측정으로 확인한다.
2. 방문 학교의 이름, 로고, 점수, 순위, 레벨이 지도·순위와 같다(M2 기준 유지).
3. 관전 클릭은 득점하지 않고, 토스트로 안내한다.
4. 지도로 돌아가기, 내 학교로 돌아가기, 방명록 보기·쓰기를 모두 새 위치에서 할 수 있다. 지도로 돌아가면 지도 문맥(권역, 검색어)이 복원된다.
5. 메인 게임 화면은 캡처와 기존 테스트 기준으로 바뀌지 않는다.
6. `npm run lint`, `npm test`, `npm run build`와 관련 e2e가 통과한다.
