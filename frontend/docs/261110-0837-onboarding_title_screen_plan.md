## 3. 대안 비교 (타이틀 그림)

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A. 타이틀 전용 캠퍼스 장면 (권고)** | 게임 캠퍼스 렌더러로 타이틀 전용 배치 하나를 그린다. 하늘에 로고, 가운데에 시계탑, 앞쪽에 정문으로 이어지는 길과 학생들 | 게임 화면과 같은 그림체와 HD 에셋을 쓴다. 스크린샷이 아니라 장면이라 잘림·흐림이 없다. 배치 검증 규칙(길 위 소품 금지 등)을 그대로 쓸 수 있다 | `CampusScene`이 레벨 번호로만 배치를 받아서 배치를 직접 받는 입력이 필요하다(5-1) |
| B. Lv.10 스크린샷을 정사각형 배경으로 | `lv10.webp`를 화면 가득 깔고 로고를 얹는다 | 가장 간단하다 | 여전히 스크린샷이다. 건물과 소품이 빽빽해 로고가 묻힌다. 하늘 영역이 좁아 로고 자리를 따로 만들기 어렵다 |
| C. 에셋 콜라주 | 개별 PNG를 HTML로 직접 배치한 포스터식 구성 | 시계탑을 크게 키우는 등 자유롭다 | 깊이 정렬과 배율을 손으로 맞춰야 한다. 정수가 아닌 배율에서 픽셀이 뭉개질 수 있다. 렌더러가 하나 더 생긴다 |

권고 근거(에이전트 판단): A는 이미 검증된 렌더러와 에셋을 쓰고, 사용자가 지우라고 한 "스크린샷을 올려 둔 방식"을 반복하지 않는다. B는 지시의 취지와 맞지 않고, C는 같은 일을 두 번째 방식으로 하게 된다.

## 4. 권고 배치 (A안)

정사각형 프레임(내용 폭 기준 약 308×308)을 화면 가득 쓴다.

```text
┌──────────────────────────────┐
│ ☁        ☀           ☁       │  하늘: sun, cloud-1~4 (기존 에셋)
│        ▛ 대대대 ▜             │  로고: 기존 글자 로고(노란 글자·검은 외곽선)
│   [전국 대학 대항전 픽셀 클리커]   │  빨간 띠 부제는 유지
│▁▂▃▅▆ horizon-forest ▆▅▃▂▁   │  원경 숲 (기존)
│ 🌸   ▟ main-clocktower ▙   🌸 │  가운데 시계탑, 양옆 벚나무(tree-cherry-1·2)
│  lamp  ░░ 광장 paving ░░  lamp │  광장·가로등·화단(flowerbed)
│ 🧑‍🎓   ░░░ 길 ░░░    🧑‍🎓  🐕   │  학생(student-walk)·강아지가 시계탑으로 걷는다
│ ▓ hedge ▓  ░ 길 ░  ▓ hedge ▓ │  앞쪽: 낮은 울타리(hedge-low)와 길 끝
└──────────────────────────────┘
```

- **구도:** 위쪽 약 40%를 하늘로 비워 로고 자리를 만든다. 지평선은 게임 레벨보다 낮게 둔다. 길은 화면 아래 가운데에서 시계탑 정문으로 올라가 "입학해서 캠퍼스로 들어가는" 느낌을 준다.
- **에셋:** 모두 기존 에셋이다: `sun`, `cloud-*`, `horizon-forest`, `main-clocktower`, `tree-cherry-*`, `lamp`, `flowerbed-*`, `hedge-low`, `student-walk-*`, `dog`, `tex-grass-*`, `tex-paving`. 새 에셋은 필요 없다.
- **로고:** 현재 글자 로고와 빨간 띠를 하늘 위에 그대로 둔다. 흔들림 애니메이션(`animate-logo-bounce`)은 유지하되, 지금은 동작 줄이기 설정에서도 움직이므로(`src/index.css:271-274`에 빠져 있음) 그 설정에서는 멈추게 한다.
- **해와 구름:** 노란 사각형과 흰 사각형 구름을 지우고 게임의 `sun`·`cloud` 에셋을 쓴다.
- **시간대:** 타이틀은 낮으로 고정한다. 글자 로고가 밤 하늘에서는 대비가 달라지기 때문이다(7절 D3).
- **접근성:** 장면 전체를 `role="img"`로 묶고 이름을 "대대대 — 전국 대학 대항전 픽셀 클리커 타이틀"로 한다. 로고 글자는 화면 읽기 도구가 읽을 수 있게 둔다.

### 선택: 추가 에셋 G5 정문 아치 (7절 D2)

앞쪽 아래에 대학 정문 아치(돌기둥 두 개와 가로 보)를 두면 "입학" 주제가 분명해진다. 현재 에셋 중에는 정문이 없다. 이전과 같이 herdr → Pi로 영어 프롬프트를 보내 생성하고, 글자를 넣지 않는다(학교 이름은 이미지 생성이 정확히 쓰지 못한다). 1안을 먼저 기존 에셋만으로 만들고, 허전하면 추가하는 순서를 권한다.
