## 1. 대결 시작 일시

```text
신청 폼: 상대 · 형식 · 기간 · [시작 일시 (KST)]
  허용: 09:00~22:00 · 30분 단위 · 최소 1시간 후 ~ 최대 7일 이내
  범위 밖 → 오류 표시 + 신청 버튼 비활성
[시연] 상대 수락
  희망 시각까지 1시간 미만 남았으면 → 수락 거절 (재신청 안내)
  아니면 → 희망 시각 그대로 예정 → 진행 → 종료
```

- 기본값은 지금 기준으로 가장 이른 허용 시각입니다. 예를 들어 21:50에 열면 다음 날 09:00이 기본값입니다.
- 신청 목록과 대결 현황에 `희망 시작` 또는 `시작` 시각이 표시됩니다.

## 2. 캠퍼스 낮/밤 연출·광원

| 시간대 (KST) | 화면 |
|---|---|
| 새벽 05–07 · 노을 17–19 | 따뜻한 색조와 측면 빛 |
| 낮 07–17 | 원본에 가깝게, 은은한 햇살 |
| 밤 19–05 | 남색 색조와 창문 불빛 |

- 시간대 경계에서는 20분 동안 서서히 바뀝니다.
- 상단 `[시연] 시간대` 선택(자동/새벽/낮/노을/밤)으로 지금 시각과 상관없이 확인할 수 있습니다.
- 적용 화면은 메인 캠퍼스와 방문 화면 3종입니다. 온보딩·지도·순위·상점에는 적용하지 않습니다.
- 클릭을 막지 않고, 움직임 줄이기 설정에서는 애니메이션이 꺼집니다.
- 밤 전용 이미지는 아직 없어서 낮 이미지 위에 색을 덧씌웁니다. `CampusSprite`의 `variant` 자리에 밤 이미지를 넣을 수 있습니다.

## 3. 다른 사용자 클릭 파티클

```text
1초마다: 내 클릭 수 전송 → 응답으로 다른 사용자의 1초 클릭 수 수신 (지금은 목업 소스)
  → 최대 20개 파티클을 1초 동안 나눠서 표시 (화면 전체 동시 최대 40개)
  → 클릭이 20개보다 많으면 파티클 하나가 여러 클릭을 대표 (+N 표시)
```

- 색은 시간대를 따릅니다. 낮에는 하늘색, 밤에는 불빛색입니다.
- 상단 말풍선 숫자도 같은 값을 씁니다(`[시연] … 다른 사용자 N회 클릭 · 점수 미반영`).
- 점수와 순위에는 영향이 없습니다. 방문·대결 화면에는 파티클이 나오지 않습니다.
- **서버를 연동할 때**는 `useMockOtherClicks`에 넘기는 `source`(`exchange(myClicks) → { otherClicks }`)만 API로 바꾸면 됩니다. 서버는 요청자 본인의 클릭을 제외하고 응답해야 합니다.
