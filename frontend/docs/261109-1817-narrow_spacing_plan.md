## 2. 수정 전 실측과 수정

수정 전 값은 main 빌드(`6f440a9`)를 Chromium 156에서 측정했다.

| ID | 수정 전 | 수정 |
|---|---|---|
| M6-D1 | 360×740에서 강화 미리보기 "30 → 40점"이 41/43px 폭으로 잘려 "30 → 4…"로 보였다. 390·430·가로에서는 전체가 보였다 | 미리보기 줄을 줄바꿈 가능하게 바꿨다. 수치는 자르지 않고, 폭이 모자라면 `업그레이드` 버튼이 다음 줄로 내려간다(`src/components/ShopScreenPhone.tsx:380`) |
| M6-D2 = M4 #5 | 인증 코드 단계에서 `PhoneFrame`의 `justify-between`이 세 블록(학교 카드·목업 메일함·입력 폼)을 벌려 블록 사이가 131·139px(가로 130·138px) 비었다 | 코드 단계만 세 블록을 한 묶음(`gap-3`, 12px)으로 세로 가운데 정렬했다(`src/components/onboarding/OnboardingSteps.tsx:203`). `PhoneFrame`은 이메일·프로필 단계도 쓰므로 바꾸지 않았다 |
| T44-D3 | 지도 검색 상자 외곽이 48px(입력 44 + 테두리 2×2)이었다 | 테두리를 레이아웃을 차지하지 않는 안쪽 그림자로 그려 외곽을 44px로 맞췄다(`src/components/MapParts.tsx:88`). 위·왼쪽 3px, 오른쪽·아래 2px 선 모양은 같다 |
| 360px 터치 측정 | `tests/e2e/touch-targets.mjs`가 390×844·844×390만 측정했고, 지도 목록을 펼친 상태도 빠져 있었다 | 360×740 세로 실행과 "지도 목록 펼침" 상태를 추가했다(`tests/e2e/touch-targets.mjs:97`, `:145`). 360px에서 미달은 0개라 화면 수정은 필요 없었다 |
